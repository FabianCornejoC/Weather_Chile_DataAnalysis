## Weather Data Analysis – Chile

### Objective
Analyze historical weather data from Chile to identify patterns and trends in temperature and precipitation.

### Data Source
Public datasets provided by the Chilean Civil Aviation Authority (DGAC), obtained through Chilean public data platforms (INE).

### Tools & Libraries
- Python
  - Pandas
  - NumPy
  - Matplotlib
- Jupyter Notebook

### Process
1. Data collection and integration from public sources  
2. Data cleaning and preprocessing  
3. Exploratory Data Analysis (EDA)  
4. Visualization of temperature and precipitation trends  

### Key Insights
- Identification of seasonal precipitation patterns  
- Analysis of temperature variations across time  
- Detection of anomalous weather events  

### Conclusion
This project demonstrates the ability to clean, analyze, and visualize real-world datasets, transforming raw data into meaningful insights that can support data-driven decision making.
